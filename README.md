# ParentAI

Аватар родителя, камера ребёнка и голосовая помощь с заданиями. Python работает на Mac, Three.js и MediaPipe — в браузере. Создание нового аватара — через встроенный облачный сканер Avaturn. Qwen и Ollama не нужны.

## Запуск

На подготовленном Mac: дважды нажмите `ParentAI.command` или выполните `.venv/bin/python run_app.py`. Откроется http://127.0.0.1:8766. Если порт занят, добавьте `--port 0`. Завершение сервера — Ctrl+C.

Для новой установки нужен Python 3.11:

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp parentai.env.example parentai.env
.venv/bin/python setup_voice.py --install-model
.venv/bin/python run_app.py
```

XTTS предлагает принять лицензию; приложение не принимает её автоматически. «Моя запись» работает без XTTS, но воспроизводит только записанное напоминание. Для новых ответов голосом родителя нужен режим клонирования и установленная модель. Можно выбрать обычный голос Яндекса: он требует доступа к SpeechKit TTS и оплачивается отдельно.

1. На шаге «Ваш образ» разрешите Avaturn обработать снимки и нажмите «Создать мой аватар». Сканер открывается прямо в ParentAI. Сделайте снимки по его инструкции и завершите создание анимируемого аватара T2. Экспорт автоматически загружается, проверяется и сохраняется; скачивать файлы, расставлять точки или делать модель самостоятельно не нужно. Предпросмотр показывает голову, шею и верх одежды с пропорциями полученной модели.
2. Запишите 20 секунд образца родителя, прослушайте и создайте голос.
3. Начните занятие: откроется экран с аватаром, камерой и помощью.
4. На шаге «К занятию» явно показано, включится ли микрофон. На экране занятия его состояние видно над аватаром: подключение, включён, слышу речь, пауза обработки, выключен или ошибка. По умолчанию режим без кнопки включается при начале занятия. Скажите «помоги» или задайте вопрос и сделайте паузу. SpeechKit получает только завершённые фрагменты вероятной речи; вопросы и просьбы направляются в YandexGPT. Переключатель позволяет отключить прослушивание. Ручная кнопка и текст остаются доступны.
5. Отвечайте в том же диалоге. «Новое задание» сбрасывает историю и этап подсказок.

Постоянный микрофон работает только на экране активного занятия. Локальный детектор использует порог шума, длительность речи, паузу 0,85 секунды, фильтрацию частот и браузерное подавление эха/шума. Во время речи аватара и ещё секунду после неё вход игнорируется. После подсказки в течение минуты принимаются короткие ответы ребёнка. Это VAD и фильтр текста, не распознавание конкретного говорящего: телевизор с человеческой речью иногда может пройти фильтр. Перерыв отключает камеру, микрофон, звук и отменяет ответ. Камера проверяет присутствие лица, а не внимание или правильность решения.

## Подключение сканера — один раз владельцем приложения

Создайте бесплатный проект в [портале Avaturn](https://developer.avaturn.me). Включите аватары с анимацией лица T2. Запишите имя своего проекта в локальный `parentai.env` и перезапустите ParentAI:

```text
PARENTAI_AVATURN_SUBDOMAIN=имя-вашего-проекта
```

Например, для `parentai.avaturn.dev` значение — `parentai`. Это настройка владельца приложения, а не каждого родителя. Без неё интерфейс сообщает, что сканер ещё не подключён; демонстрационный домен не подставляется автоматически. Нашего проекта Avaturn пока нет, поэтому создание личного аватара через облако ещё не проверено.

[Базовое встраивание Avaturn бесплатно](https://docs.avaturn.me/docs/integration/web/html/); Pro с расширенным API и интерфейсом оплачивается отдельно. Этот код использует обычное встраивание, не покупает подписку. Родитель работает с интерфейсом и условиями аккаунта Avaturn. Доступность T2 и авторизацию нужно проверить в настройках созданного проекта.

Проверка официального `demo` подтвердила SDK handshake и показала экран входа Avaturn на английском. В бесплатном варианте родителю потребуется аккаунт Avaturn; полностью собственная авторизация без входа в Avaturn относится к [Pro](https://avaturn.dev/pricing/). В ParentAI добавлены пояснения к кнопкам Sign in/Next и голосовое вступление. Вход, регистрация и загрузка личных снимков в этой проверке не выполнялись.

Сканер загружается только после явного согласия родителя. Его фотографии обрабатывает Avaturn; это внешняя служба, а не сервер ParentAI. Камера ребёнка и образец голоса туда не отправляются. Готовый аватар сохраняется приватно в `data/`, доступен через API с токеном и не публикуется в Git.

## Yandex

Заполните `parentai.env` по примеру. Он исключён из Git.

```text
YANDEX_API_KEY=ключ_для_YandexGPT
YANDEX_FOLDER_ID=идентификатор_каталога
PARENTAI_TUTOR_MODEL=yandexgpt-5-lite
YANDEX_SPEECHKIT_API_KEY=ключ_для_SpeechKit
YANDEX_TTS_API_KEY=ключ_для_быстрой_озвучки
```

YandexGPT: область `yc.ai.languageModels.execute`, роль `ai.languageModels.user`. SpeechKit: область `yc.ai.speechkitStt.execute`, роль `ai.speechkit-stt.user`. Если отдельный ключ SpeechKit пуст, используется `YANDEX_API_KEY`, которому нужны обе области доступа. [API-ключи](https://yandex.cloud/ru/docs/iam/concepts/authorization/api-key), [модели YandexGPT](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models), [SpeechKit STT](https://yandex.cloud/ru/docs/speechkit/stt/api/request-api).

Для обычного быстрого голоса нужны область `yc.ai.speechkitTts.execute` и роль `ai.speechkit-tts.user`. `YANDEX_TTS_API_KEY` при отсутствии заменяется ключом SpeechKit/YandexGPT с нужными правами. [SpeechKit TTS](https://aistudio.yandex.ru/ru/docs/speechkit/tts/request).

YandexGPT и SpeechKit платные. Аудио вопроса отправляется в SpeechKit после локального обнаружения речи либо по ручной кнопке, текст и короткая история — в YandexGPT. Камера ребёнка, образец родителя и синтезированный голос в Yandex не отправляются. Снимки для аватара передаются Avaturn только при запуске сканирования с разрешением родителя. Вопрос до 25 секунд, текст до 4000 знаков; подсказка до 180 токенов, полное объяснение до 450. В режиме обычного голоса текст ответа также отправляется в SpeechKit TTS; образец родителя туда не передаётся.

## Реализовано

- Новый путь: встроенный Avaturn SDK 1.1.0 → автоматический экспорт → проверка GLB → приватный профиль v6 → Three.js GLTFLoader. Внешние ресурсы модели, неподвижное лицо, циклические скелеты и чрезмерные размеры отклоняются. Неудачный экспорт сохраняет предыдущий профиль.
- Настоящие суставы головы и шеи и формы лица ARKit управляют поворотами, морганием и губами. Волосы, уши и одежда принадлежат полученной модели; фотография не растягивается в программе для имитации поворота. Пропорции частей отдельно не изменяются.
- Тёплый округлый интерфейс: настройка родителя, экран ребёнка с заметным состоянием микрофона, голосовые вопросы, перерыв. Ручной редактор контуров и процедурная сборка аватара удалены из активного приложения.
- SpeechKit получает моно PCM16 16 кГц без WAV-заголовка; запись проверяется и пересэмплируется в Python.
- Сервер отслеживает три подсказки, затем разрешает полное объяснение. Промпт просит проверять попытки ребёнка, хвалить конкретный успех и общаться тепло. Это инструкция модели, не гарантия правильности ответа.
- Текст появляется после YandexGPT. Один процесс XTTS прогревается при открытии приложения с сохранённым клоном и при начале занятия. Образец говорящего кэшируется по хэшу. Первые WAV-фрагменты доступны до завершения ответа; браузер планирует их по аудиочасам. Память освобождается после занятия либо 5 минут простоя. Лимит одного ответа — 10 минут. Обычный голос Яндекса позволяет обойти локальную генерацию. Напоминания не перебивают вопрос и ответ.
- Диалоги и ответы временные. Профили и напоминания сохраняются в `data/`, которая исключена из Git.

## Ограничения

Avaturn создаёт узнаваемую голову по снимкам и подбирает тело, волосы и одежду из своих вариантов. Это не точное сканирование реальных плеч, футболки и каждой пряди. [Анимируемый T2 менее узнаваем, чем статический T1](https://docs.avaturn.me/docs/integration/bodies/). Личный результат ещё нужно оценить после подключения проекта и нового сканирования; демомодель не подтверждает сходство с родителем.

Старые фото-профили v1–v5 остаются в `data/` до успешного нового сканирования, но прежняя оболочка с фототекстурой больше не отображается как полноценный 3D-аватар. Для перехода к занятию нужен новый анимируемый профиль. Неподвижный T1 отклоняется с пояснением.

Lip-sync использует формы полученной модели: челюсть, смыкание, округление и растяжение губ. Русские буквы приблизительно распределяются по звучащим участкам аудио; это не точное выравнивание фонем. Синтетические зубы и язык не добавляются. Сходство голоса оценивается прослушиванием.

XTTS автоматически выбирает Apple GPU (MPS) на совместимом Mac; на других устройствах использует CPU. `PARENTAI_VOICE_DEVICE=cpu` позволяет отключить Metal. При неподдерживаемой операции до публикации первого чанка процесс переходит на CPU. Итоговый тест через рабочий процесс на этом Mac: прогрев 29,89 сек.; первый фрагмент 0,84 сек. в обоих ответах; полный WAV 3,50/3,12 сек. (аудио 3,53/3,24 сек.). Это время XTTS без STT/YandexGPT, не гарантия скорости на другом устройстве. В первой серии CPU-замеров двух прогретых ответов «Давай вспомним правило. Какой следующий шаг?» первый звук появился за 4,29/1,68 сек., весь WAV — за 10,53/6,63 сек. (без STT/YandexGPT). Холодный старт был 144,56 сек., включая первичное построение кэша шрифтов импортируемой библиотекой; кэши теперь сохраняются в `data/.cache`. При генерации медленнее реального времени поток может иметь паузы. В повторной серии первый звук занял 4,53/5,31 сек., весь ответ — 19,83/22,58 сек.; холодный старт 123,55 сек. Время заметно меняется между запусками. Мгновенная клонированная речь на CPU не гарантируется. На смартфоне его запускать не следует. Интерфейс адаптивный, но мобильный сервер с HTTPS, авторизацией и разделением профилей ещё не реализован. Текущий сервер слушает только localhost; это не готовый интернет-сервис.

Технический выбор и пошаговый план с кодом: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

MediaPipe, Three.js и XTTS не российские разработки. Российские технологии здесь используются для облачных STT и генерации ответов. Условия компонентов: [THIRD_PARTY.md](THIRD_PARTY.md).

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
node --test tests/*.test.mjs
node --input-type=module --check < web/app.js
```

Проверяются модель и защищённое сохранение, сохранность прежнего профиля при ошибке, запрет внешних ресурсов, допустимые адреса экспорта, формы губ, плавное внимание при речи, аудио, STT/TTS, диалоги и отмена. Сохранены также тесты прежней геометрии для совместимости; она больше не используется активным интерфейсом. Облачные ответы в тестах заменены фикстурами без расхода API. Тесты не измеряют сходство и фотореализм.

`AvatarMotion` плавно направляет голову и взгляд к ребёнку при локальном обнаружении речи; `ModelAvatar` применяет позу к скелету и формам лица. В режиме покоя есть небольшие кивки, покачивание и смена взгляда. Уважает настройку уменьшения движения.

Ресурсы Three.js/MediaPipe/Avaturn SDK скачиваются при запуске с закреплённых адресов из `download_assets.py`; веса не включены в Git. После установки камера, сохранённый аватар и синтез работают без интернета; новое сканирование требует Avaturn, вопросы — Yandex. `legacy/` хранит прежний код. Старое окружение Mac содержит лишние зависимости прошлой версии; чистая установка по `requirements.txt` отдельно не проверена.
