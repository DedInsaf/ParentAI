# ParentAI

ParentAI помогает ребёнку самостоятельно делать домашнее задание с помощью наводящих подсказок, а родителю даёт короткий отчёт и предлагает подключиться только тогда, когда это действительно нужно. Аватар и голос родителя — дополнительный эмоциональный слой, а не единственная ценность продукта. Первая версия рассчитана на работающих родителей детей 2–6 классов.

Three.js и MediaPipe работают в браузере. Сканирование и построение аватара выполняются на устройстве; фотографии родителя не отправляются во внешний сервис. Камера проверки присутствия выключена по умолчанию и включается родителем отдельно перед занятием.

## Запуск

На подготовленном Mac дважды нажмите `ParentAI.command` или выполните `.venv/bin/python run_app.py`. Откроется http://127.0.0.1:8767. Если порт занят, добавьте `--port 0`. Завершение сервера — Ctrl+C.

Для новой установки нужен Python 3.11:

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp parentai.env.example parentai.env
.venv/bin/python run_app.py
```

Базовая установка не загружает XTTS-v2. Его модель и результаты разрешены только для некоммерческого использования, поэтому клонирование выключено по умолчанию и не должно использоваться в платной beta. Для отдельной некоммерческой разработки: установите `requirements-xtts.txt`, явно задайте `PARENTAI_ENABLE_XTTS=1`, затем запустите `.venv/bin/python setup_voice.py --install-model` и примите лицензию самостоятельно. Обычный динамический голос работает через платный SpeechKit TTS v3; заранее записанное напоминание родителя не обращается к облаку.

## Как пользоваться

1. При первом запуске создайте аккаунт: укажите логин, почту, пароль и подтверждение пароля. В дальнейшем можно входить по логину или почте.
2. На шаге «Ваш образ» разрешите локальную обработку и нажмите «Создать мой аватар». Сканер сам сделает шесть кадров: прямо, два небольших и два более сильных поворота, затем портрет с шеей и плечами. Точки вручную расставлять не нужно.
3. Дождитесь объёмного предпросмотра и проверьте поворот. Снимки и профиль сохраняются только в локальной папке `data/`, которая исключена из Git.
4. Запишите голос родителя, прослушайте его и выберите режим ответа.
5. На шаге «К занятию» отдельно выберите, нужны ли микрофон и локальная проверка присутствия камерой. После начала откроется экран с аватаром и полем помощи.
6. Ребёнок может сказать «помоги» и вопрос без нажатия кнопки. Сначала аватар даёт подсказки и наводящие вопросы; после нескольких попыток может объяснить решение полностью.

Учётные записи хранятся в локальной SQLite-базе `data/users.sqlite3`. Пароли не записываются в открытом виде: сохраняются индивидуальная соль и PBKDF2-хеш. Ключи сессий также не хранятся в базе напрямую; браузер получает их в недоступной JavaScript `HttpOnly`-cookie.

Для тестирования можно создать локального администратора:

```sh
.venv/bin/python manage_users.py create-admin --generate-password
```

Команда один раз покажет случайный пароль. Администратор не ограничен тарифными квотами, но все вызовы Yandex и их реальная стоимость продолжают учитываться. Роль нельзя получить через публичную регистрацию. База аккаунтов и пароль исключены из Git; существующего пользователя можно повысить командой `.venv/bin/python manage_users.py promote ЛОГИН`.

Микрофон без кнопки работает только во время занятия. Локальный фильтр отсеивает тишину, гул и короткие звуки; во время речи аватара вход отключён. Это не распознавание конкретного человека, поэтому речь телевизора иногда может пройти фильтр. Перерыв выключает камеру и микрофон. Камера проверяет присутствие лица, а не внимание или правильность решения.

## Локальный 3D-аватар

MediaPipe строит 478 трёхмерных ориентиров лица. ParentAI выравнивает их в нейтральную позу, создаёт сетку лица и замыкает её объёмной формой затылка. Боковые снимки дополняют текстуру щёк и висков. Специализированная модель MODNet отделяет человека от фона на широком портрете: сохраняет мягкий край волос, настоящую шею, ворот и одежду. Контур шеи, плеч и волос переносится на объёмную сетку в масштабе исходного снимка. MediaPipe дополнительно определяет части портрета; его жёсткие категории не используются для вырезания волос.

MODNet выполняется в отдельном потоке браузера через ONNX Runtime Web/WASM. Веса около 26 МБ загружаются при подготовке приложения и затем читаются с локального хоста. Время обработки зависит от устройства; искусственной задержки нет. Во время работы видны этапы обработки, а в предпросмотре можно раскрыть «Проверить, как удалён фон» и отдельно оценить исходный снимок без фона. Сохранённые портреты обрабатываются новым способом при открытии приложения, пересканирование для этого не требуется.

Модель поворачивается как геометрия: фотография не растягивается при повороте. Голова вращается относительно шеи, аватар дышит, моргает, слегка отводит взгляд и плавно возвращается к ребёнку при речи. Рот деформирует губы и нижнюю часть лица; внутри находится тёмная полость без искусственных зубов и языка.

Обычная RGB-камера не видит затылок, точную форму ушей, объём причёски и плечи под одеждой. Поэтому локальный результат рассчитан на фронтальный разговор и небольшие повороты, а не на круговой студийный скан. Волосы и задняя часть головы аппроксимируются. Это ограничение режима без сервера и depth-камеры.

Старые профили v1–v5 сохраняются до успешного нового сканирования, но интерфейс просит создать новый профиль v7. Старые проверенные GLB v6 всё ещё читаются для совместимости.

## Yandex

Заполните `parentai.env` по примеру; файл исключён из Git.

```text
YANDEX_API_KEY=ключ_для_YandexGPT
YANDEX_FOLDER_ID=идентификатор_каталога
PARENTAI_TUTOR_MODEL=yandexgpt-5-lite
YANDEX_SPEECHKIT_API_KEY=ключ_для_SpeechKit
YANDEX_TTS_API_KEY=ключ_для_быстрой_озвучки
PARENTAI_ENABLE_XTTS=0
```

YandexGPT требует область `yc.ai.languageModels.execute` и роль `ai.languageModels.user`. Для SpeechKit STT нужны `yc.ai.speechkitStt.execute` и `ai.speechkit-stt.user`; для TTS — `yc.ai.speechkitTts.execute` и `ai.speechkit-tts.user`. Если отдельные ключи пусты, используется `YANDEX_API_KEY` с соответствующими правами. Документация: [API-ключи](https://yandex.cloud/ru/docs/iam/concepts/authorization/api-key), [модели YandexGPT](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models), [SpeechKit STT](https://yandex.cloud/ru/docs/speechkit/stt/api/request-api), [SpeechKit TTS](https://aistudio.yandex.ru/ru/docs/speechkit/tts/request).

YandexGPT и SpeechKit платные. В SpeechKit отправляется только законченный фрагмент вопроса после локального обнаружения речи. В YandexGPT один раз на новое задание отправляется его текст для построения внутреннего плана из трёх подсказок, контрольных вопросов и критерия ответа. Внутреннее решение ребёнку не показывается; следующие подсказки и простые проверки выполняются локально. Камера ребёнка, фотографии аватара и образец голоса родителя в Yandex не отправляются. При выборе обычного голоса Яндекса туда также отправляется сокращённый до 240 символов текст ответа.

## Тарифы, лимиты и учёт стоимости

Цены и лимиты находятся в одном файле `billing.json`. Денежные значения читаются через `Decimal`, а в SQLite хранятся целыми микро-рублями — двоичное округление `float` не используется. Перед каждым внешним вызовом сервер атомарно резервирует бюджет; после ответа заменяет оценку фактическими токенами или тарифицируемыми блоками. Начатый ответ не обрывается, даже если его фактическая стоимость оказалась выше оценки.

- Free: 5 заданий, 10 планов YandexGPT, 150 тарифицируемых секунд STT и 3 голосовых ответа в месяц; общий предохранитель — 5 ₽ внешних расходов.
- Paid beta: 120 заданий, 160 планов, 6000 тарифицируемых секунд STT и 500 блоков TTS; общий предохранитель — 85 ₽ внешних расходов. Цена beta в конфигурации — 299 ₽. Платёжной интеграции пока нет.
- При 80% любого лимита ребёнок видит спокойное предупреждение, а родитель — точный остаток. После лимита текстовая подсказка не заменяется технической ошибкой: например, при исчерпании TTS ответ остаётся на экране.

`data/usage.sqlite3` хранит только агрегаты: идентификаторы пользователя и занятия, тип операции, токены, длительность, блоки, стоимость, провайдера и модель. Текст задания, переписка, фото и аудио туда не записываются. Защита от повторов использует идентификатор запроса; одинаковая параллельная операция не запускается второй раз. Также действуют короткие серверные интервалы и минутные ограничения.

Родительский блок на шаге «К занятию» показывает тариф, количество заданий и подсказок, самостоятельные решения, сложности, стоимость внешних сервисов и остаток лимита. Доступный только администратору агрегированный endpoint `/api/metrics/cost` возвращает P50/P90/P99 стоимости активного пользователя за текущий месяц.

Пример при актуальных на 10 октября 2026 года ценах: план на 1200 входных и 500 выходных токенов стоит около 0,34 ₽; два коротких STT-фрагмента тарифицируются как 30 секунд и стоят 0,3252 ₽; один ответ TTS v3 до 250 символов — 0,1626 ₽. Итого одно такое задание — около 0,8278 ₽, а 60 заданий — около 49,67 ₽ на активного пользователя. Это пример, фактическая стоимость видна в отчёте.

## Реализовано

- Локальная регистрация и вход по логину или почте; закрытые API, записи голоса и аватар доступны только после входа.
- Встроенное сканирование без переходов на другие сайты; шесть кадров снимаются автоматически с крупными видимыми и голосовыми подсказками.
- Локальный профиль v7 с сеткой лица, затылком, ушами, волосами, шеей и верхом одежды. Сохранение проверяет формат, порядок кадров, углы, размер и данные ориентиров.
- Плавные повороты головы, кивки, дыхание, моргание и внимание к ребёнку. Lip-sync различает смыкание, округление и растяжение губ, но не является точным фонемным выравниванием.
- Экран занятия с заметным состоянием микрофона, режимом без кнопки, ручной записью вопроса, текстовым вводом и перерывом.
- Диалог с этапами подсказок. Соблюдение педагогической инструкции зависит от YandexGPT и не гарантирует фактическую правильность ответа.
- Единый серверный учёт LLM/STT/TTS по пользователю и занятию, бюджеты Free/Paid, защита от повторов и отчёт с P50/P90/P99.
- Один скрытый структурированный план на задание; повтор, переход между тремя подсказками и однозначные ответы обрабатываются локально.
- Сменяемые провайдеры: продуктовая логика занятия не зависит от конкретной реализации YandexGPT, STT или TTS. SpeechKit TTS переведён на API v3. XTTS-v2 оставлен только как явно включаемый некоммерческий режим.

## До платной beta

Нужны отдельное подтверждение и внешние решения для: выбора платёжного провайдера и обработки возвратов; юридически допустимого коммерческого голоса родителя вместо XTTS-v2; OCR-провайдера для фото задания и его лимитов; серверного развёртывания с разделением локальных аватаров семей; политики согласия и удаления данных. Код уже содержит модели Free/Paid и точку `UsageStore.set_subscription`, но сам не принимает платежи и не повышает тариф пользователю.

## Ограничения и известные риски

Создание геометрии, MediaPipe и Three.js подходят для MacBook M3 16 ГБ и современных смартфонов. XTTS-v2 не подходит для коммерческой версии из-за лицензии и слишком тяжёл для телефона. Для динамической озвучки используется обычный голос SpeechKit.

Текущая сборка запускается как локальное Python-приложение для macOS. Веб-интерфейс адаптивный, но самостоятельная мобильная упаковка, безопасное хранение ключей и запуск фоновой части на iOS/Android ещё не реализованы. Перенос интерфейса и локальной 3D-реконструкции на телефон возможен; секреты Yandex нельзя помещать в клиентское приложение.

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
node --test tests/*.test.mjs
node --input-type=module --check < web/app.js
```

Тесты проверяют хранение профиля, геометрию, движение, формы губ, аудио, STT/TTS, диалоги и отмену. Они не измеряют визуальное сходство с конкретным человеком; это нужно оценивать на реальном скане при хорошем рассеянном свете.
