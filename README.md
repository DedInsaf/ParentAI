# ParentAI

Аватар родителя, камера ребёнка и голосовая помощь с заданиями. Python работает на Mac/сервере, Three.js и MediaPipe — в браузере. Qwen и Ollama не нужны.

## Запуск

На подготовленном Mac: дважды нажмите `ParentAI.command` или выполните `.venv/bin/python run_app.py`. Откроется http://127.0.0.1:8766. Если порт занят, добавьте `--port 0`. Завершение сервера — Ctrl+C.

Для новой установки нужен Python 3.11:

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp parentai.env.example parentai.env
.venv/bin/python setup_voice.py --install-model
.venv/bin/python run_app.py
```

XTTS предлагает принять лицензию; приложение не принимает её автоматически. «Моя запись» работает без XTTS, но воспроизводит только записанное напоминание. Для новых ответов голосом родителя нужен режим клонирования и установленная модель. Можно выбрать обычный голос Яндекса: он требует доступа к SpeechKit TTS и оплачивается отдельно.

1. Откройте шаг «Лицо и плечи», включите камеру и начните сканирование. Экран камеры развернётся, инструкции прозвучат голосом; каждый снимок подтверждается сигналом. Если браузер не поддерживает озвучивание, остаются крупные надписи на камере. После двух поворотов отодвиньте камеру для четвёртого кадра с шеей, плечами и футболкой. Затем проверьте модель спереди, сбоку и кнопкой «Проверить речь».
2. Запишите 20 секунд образца родителя, прослушайте и создайте голос.
3. Начните занятие: откроется экран с аватаром, камерой и помощью.
4. Микрофон без кнопки включается при начале занятия. Скажите «помоги» или задайте вопрос и сделайте паузу. SpeechKit получает только завершённые фрагменты вероятной речи; вопросы и просьбы направляются в YandexGPT. Переключатель позволяет отключить прослушивание. Ручная кнопка и текст остаются доступны.
5. Отвечайте в том же диалоге. «Новое задание» сбрасывает историю и этап подсказок.

Постоянный микрофон работает только на экране активного занятия. Локальный детектор использует порог шума, длительность речи, паузу 0,85 секунды, фильтрацию частот и браузерное подавление эха/шума. Во время речи аватара и ещё секунду после неё вход игнорируется. После подсказки в течение минуты принимаются короткие ответы ребёнка. Это VAD и фильтр текста, не распознавание конкретного говорящего: телевизор с человеческой речью иногда может пройти фильтр. Перерыв отключает камеру, микрофон, звук и отменяет ответ. Камера проверяет присутствие лица, а не внимание или правильность решения.

## Yandex

Заполните `parentai.env` по примеру. Он исключён из Git.

```text
YANDEX_API_KEY=ключ_для_YandexGPT
YANDEX_FOLDER_ID=идентификатор_каталога
PARENTAI_TUTOR_MODEL=yandexgpt-5-lite
YANDEX_SPEECHKIT_API_KEY=ключ_для_SpeechKit
YANDEX_TTS_API_KEY=ключ_для_быстрой_озвучки
```

YandexGPT: область `yc.ai.languageModels.execute`, роль `ai.languageModels.user`. SpeechKit: область `yc.ai.speechkitStt.execute`, роль `ai.speechkit-stt.user`. Если отдельный ключ SpeechKit пуст, используется `YANDEX_API_KEY`, которому нужны обе области доступа. [API-ключи](https://yandex.cloud/ru/docs/iam/concepts/authorization/api-key), [модели YandexGPT](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models), [SpeechKit STT](https://yandex.cloud/ru/docs/speechkit/stt/api/request-api).

Для обычного быстрого голоса нужны область `yc.ai.speechkitTts.execute` и роль `ai.speechkit-tts.user`. `YANDEX_TTS_API_KEY` при отсутствии заменяется ключом SpeechKit/YandexGPT с нужными правами. [SpeechKit TTS](https://aistudio.yandex.ru/ru/docs/speechkit/tts/request).

YandexGPT и SpeechKit платные. Аудио вопроса отправляется в SpeechKit после локального обнаружения речи либо по ручной кнопке, текст и короткая история — в YandexGPT. Фото, камера, образец родителя и синтезированный голос в облако не отправляются. Вопрос до 25 секунд, текст до 4000 знаков; подсказка до 180 токенов, полное объяснение до 450. В режиме обычного голоса текст ответа также отправляется в SpeechKit TTS; образец родителя туда не передаётся.

## Реализовано

- Подогнанная сетка лица соединена с отдельной объёмной оболочкой головы. Уши с раковиной, шея, объёмные плечи и верх футболки, три варианта процедурных волос и выбор цвета. Проверка глубины включена, голова поворачивается отдельно от неподвижных шеи и плеч. Фототекстуры шеи и одежды берутся из четвёртого кадра; видимые боковые треугольники лица смешиваются в UV-атласе с боковыми фото.
- Повороты, наклоны, моргание и движение рта по аудио. Новые ответы получают приближённые русские формы губ: смыкание, округление, растяжение.
- SpeechKit получает моно PCM16 16 кГц без WAV-заголовка; запись проверяется и пересэмплируется в Python.
- Сервер отслеживает три подсказки, затем разрешает полное объяснение. Промпт просит проверять попытки ребёнка, хвалить конкретный успех и общаться тепло. Это инструкция модели, не гарантия правильности ответа.
- Текст появляется после YandexGPT. Один процесс XTTS прогревается при открытии приложения с сохранённым клоном и при начале занятия. Образец говорящего кэшируется по хэшу. Первые WAV-фрагменты доступны до завершения ответа; браузер планирует их по аудиочасам. Память освобождается после занятия либо 5 минут простоя. Лимит одного ответа — 10 минут. Обычный голос Яндекса позволяет обойти локальную генерацию. Напоминания не перебивают вопрос и ответ.
- Диалоги и ответы временные. Профили и напоминания сохраняются в `data/`, которая исключена из Git.

## Ограничения

После обновления сканирования старую модель лучше переснять: старый фронтальный кадр мог быть снят с поворотом. Новый профиль явно отмечает фронтальный снимок; наклон и поворот убираются из геометрии, а предпросмотр при настройке не вращается сам. Фотография и точки извлекаются из одного замороженного кадра. Шея теперь имеет плавный профиль без расширяющейся подставки и текстуру из области под подбородком. Для её захвата приложение проверяет, что шея помещается в кадр; форма шеи остаётся подогнанной моделью, а не измеренным сканом.

Это упрощённая объёмная голова, не фотореалистичный скан. Три снимка подгоняют лицо и смешивают видимые щёки в фототекстуре; четвёртый даёт материал шеи и одежды, но не измеряет их объём; точные уши, причёска и затылок не восстанавливаются. Lip-sync распределяет русские буквы по активным участкам аудио. Амплитуда челюсти уменьшена, добавлены отдельные упрощённые зубы и язык. У ранних фрагментов выравнивание приблизительное; это не точные времена фонем. Сходство голоса оценивается прослушиванием.

XTTS автоматически выбирает Apple GPU (MPS) на совместимом Mac; на других устройствах использует CPU. `PARENTAI_VOICE_DEVICE=cpu` позволяет отключить Metal. При неподдерживаемой операции до публикации первого чанка процесс переходит на CPU. Итоговый тест через рабочий процесс на этом Mac: прогрев 29,89 сек.; первый фрагмент 0,84 сек. в обоих ответах; полный WAV 3,50/3,12 сек. (аудио 3,53/3,24 сек.). Это время XTTS без STT/YandexGPT, не гарантия скорости на другом устройстве. В первой серии CPU-замеров двух прогретых ответов «Давай вспомним правило. Какой следующий шаг?» первый звук появился за 4,29/1,68 сек., весь WAV — за 10,53/6,63 сек. (без STT/YandexGPT). Холодный старт был 144,56 сек., включая первичное построение кэша шрифтов импортируемой библиотекой; кэши теперь сохраняются в `data/.cache`. При генерации медленнее реального времени поток может иметь паузы. В повторной серии первый звук занял 4,53/5,31 сек., весь ответ — 19,83/22,58 сек.; холодный старт 123,55 сек. Время заметно меняется между запусками. Мгновенная клонированная речь на CPU не гарантируется. На смартфоне его запускать не следует. Интерфейс адаптивный, но мобильный сервер с HTTPS, авторизацией и разделением профилей ещё не реализован. Текущий сервер слушает только localhost; это не готовый интернет-сервис.

Технический выбор и пошаговый план с кодом: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

MediaPipe, Three.js и XTTS не российские разработки. Российские технологии здесь используются для облачных STT и генерации ответов. Условия компонентов: [THIRD_PARTY.md](THIRD_PARTY.md).

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
node --test tests/*.test.mjs
node --input-type=module --check < web/app.js
```

Проверяются аудио, STT/TTS-запросы, поток WAV-фрагментов, фильтрация тишины/гула/щелчков/эха, маршрутизация русского вопроса, профиль с плечами, этапы диалога и отмена, защищённый API, профиль, атомарность банка, геометрия и движение губ. Облачные запросы заменены ответами без расхода API. Тесты не измеряют фотореализм.

Ресурсы Three.js/MediaPipe скачиваются при запуске с закреплённых адресов из `download_assets.py`; веса не включены в Git. После установки камера и синтез работают без интернета, вопросы требуют Yandex. `legacy/` хранит прежний код. Старое окружение Mac содержит лишние зависимости прошлой версии; чистая установка по `requirements.txt` отдельно не проверена.
