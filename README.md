# Адым

**Адым** в переводе с татарского означает **«шаг»**. Адым помогает ребёнку шаг за шагом самостоятельно делать домашнее задание с помощью наводящих подсказок, а родителю даёт короткий отчёт и предлагает подключиться только тогда, когда это действительно нужно. Аватар и голос родителя — дополнительный эмоциональный слой, а не единственная ценность продукта. Первая версия рассчитана на работающих родителей детей 2–6 классов.

Three.js и MediaPipe работают в браузере. Сканирование и построение аватара выполняются на устройстве; фотографии родителя не отправляются во внешний сервис. Камера проверки присутствия включена по умолчанию перед занятием, но родитель может отключить её вручную.

## Запуск

На подготовленном Mac дважды нажмите `Адым.command` или выполните `.venv/bin/python run_app.py`. Откроется http://127.0.0.1:8767. Если порт занят, добавьте `--port 0`. Завершение сервера — Ctrl+C.

Публичная информационная версия сайта находится в `public-site/`. Это отдельная статическая витрина для обычного хостинга: она показывает продукт и тарифы, но не запускает тяжёлую часть приложения и не содержит ключей, аккаунтов, базы, фотографий, голосов или моделей. До подключения серверной версии и Platega кнопки покупки на ней намеренно отключены.

Для новой установки нужен Python 3.11:

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp parentai.env.example parentai.env
.venv/bin/python setup_speech.py
.venv/bin/python run_app.py
```

`setup_speech.py` один раз загружает около 1 ГБ весов многоязычного Whisper Small в `data/models`. После этого вопросы сначала распознаются локально и обычно не расходуют SpeechKit. Если локальная модель не загрузилась или не разобрала законченный фрагмент, а ключ SpeechKit настроен, приложение использует его как резерв; аудио не сохраняется.

Базовая установка не загружает XTTS-v2. Его модель и результаты разрешены только для некоммерческого использования, поэтому клонирование выключено по умолчанию и не должно использоваться в платной beta. Для отдельной некоммерческой разработки: установите `requirements-xtts.txt`, явно задайте `PARENTAI_ENABLE_XTTS=1`, затем запустите `.venv/bin/python setup_voice.py --install-model` и примите лицензию самостоятельно. Обычный динамический голос работает через платный SpeechKit TTS v3; заранее записанное напоминание родителя не обращается к облаку.

## Как пользоваться

1. При первом запуске создайте аккаунт: укажите логин, почту, пароль, при необходимости код приглашения и подтвердите согласие с документами как совершеннолетний родитель. В дальнейшем можно входить по логину или почте.
2. На шаге «Ваш образ» разрешите локальную обработку и нажмите «Создать мой аватар». Сканер сам сделает шесть кадров: прямо, два небольших и два более сильных поворота, затем портрет с шеей и плечами. Точки вручную расставлять не нужно.
3. Дождитесь объёмного предпросмотра и проверьте поворот. Снимки и профиль сохраняются только в локальной папке `data/`, которая исключена из Git.
4. Для наиболее похожего клонированного голоса запишите три коротких образца с разной естественной интонацией, прослушайте каждый и создайте голос. Режим точной записи напоминания по-прежнему требует только одну запись.
5. На шаге «К занятию» камера уже выбрана и подключится при нажатии «Начать занятие». При желании родитель может отключить её; микрофон также настраивается отдельно. После начала откроется экран с аватаром, изображением с камеры и полем помощи.
6. Ребёнок может сказать «помоги» и вопрос без нажатия кнопки. Сначала аватар даёт подсказки и наводящие вопросы; после нескольких попыток может объяснить решение полностью.

Учётные записи хранятся в локальной SQLite-базе `data/users.sqlite3`. Пароли не записываются в открытом виде: сохраняются индивидуальная соль и PBKDF2-хеш. Ключи сессий также не хранятся в базе напрямую; браузер получает их в недоступной JavaScript `HttpOnly`-cookie.

Для тестирования можно создать локального администратора:

```sh
.venv/bin/python manage_users.py create-admin --generate-password
```

Команда один раз покажет случайный пароль. Администратор не ограничен тарифными квотами, но все вызовы Yandex и их реальная стоимость продолжают учитываться. Роль нельзя получить через публичную регистрацию. База аккаунтов и пароль исключены из Git; существующего пользователя можно повысить командой `.venv/bin/python manage_users.py promote ЛОГИН`.

В меню администратора доступна отдельная панель аккаунтов: поиск, агрегированная активность, блокировка и разблокировка, выдача или отзыв тестового тарифа, завершение всех входов и журнал действий. Пароли, разговоры, фотографии и голос в панели не отображаются. Изменение тарифа управляет доступом внутри Адым; после подключения реальных платежей отмена списания в Platega остаётся отдельной операцией.

Для проверки конкретных платных тарифов без настоящей оплаты можно создать локальные тестовые аккаунты:

```sh
.venv/bin/python manage_users.py create-test-account paid --generate-password
.venv/bin/python manage_users.py create-test-account ultra --generate-password
```

Такие аккаунты имеют обычную родительскую роль и все реальные ограничения выбранного тарифа. Они не создают подписку в Platega и не вызывают списаний.

Микрофон без кнопки работает только во время занятия. Локальный фильтр отсеивает тишину, гул и короткие звуки; во время речи аватара вход отключён. Это не распознавание конкретного человека, поэтому речь телевизора иногда может пройти фильтр. Перерыв выключает камеру и микрофон. Камера проверяет присутствие лица, а не внимание или правильность решения.

## Локальный 3D-аватар

MediaPipe строит 478 трёхмерных ориентиров лица. Адым выравнивает их в нейтральную позу, создаёт сетку лица и замыкает её объёмной формой затылка. Боковые снимки дополняют текстуру щёк и висков. Специализированная модель MODNet отделяет человека от фона на широком портрете: сохраняет мягкий край волос, настоящую шею, ворот и одежду. Контур шеи, плеч и волос переносится на объёмную сетку в масштабе исходного снимка. MediaPipe дополнительно определяет части портрета; его жёсткие категории не используются для вырезания волос.

MODNet выполняется в отдельном потоке браузера через ONNX Runtime Web/WASM. Веса около 26 МБ загружаются при подготовке приложения и затем читаются с локального хоста. Время обработки зависит от устройства; искусственной задержки нет. Во время работы видны этапы обработки, а в предпросмотре можно раскрыть «Проверить, как удалён фон» и отдельно оценить исходный снимок без фона. Сохранённые портреты обрабатываются новым способом при открытии приложения, пересканирование для этого не требуется.

Модель поворачивается как геометрия: фотография не растягивается при повороте. Голова вращается относительно шеи, аватар дышит, моргает, слегка отводит взгляд и плавно возвращается к ребёнку при речи. Рот деформирует губы и нижнюю часть лица; внутри находится тёмная полость без искусственных зубов и языка.

Обычная RGB-камера не видит затылок, точную форму ушей, объём причёски и плечи под одеждой. Поэтому локальный результат рассчитан на фронтальный разговор и небольшие повороты, а не на круговой студийный скан. Волосы и задняя часть головы аппроксимируются. Это ограничение режима без сервера и depth-камеры.

Старые профили v1–v5 сохраняются до успешного нового сканирования, но интерфейс просит создать новый профиль v7. Старые проверенные GLB v6 всё ещё читаются для совместимости.

## Yandex

Заполните `parentai.env` по примеру; файл исключён из Git.

```text
YANDEX_API_KEY=ключ_для_YandexGPT
YANDEX_FOLDER_ID=идентификатор_каталога
PARENTAI_TUTOR_MODEL=yandexgpt-5.1
PARENTAI_STT_ENGINE=local
PARENTAI_STT_MODEL=openai/whisper-small
YANDEX_TTS_API_KEY=ключ_для_быстрой_озвучки
PARENTAI_ENABLE_XTTS=0
PLATEGA_MERCHANT_ID=идентификатор_магазина
PLATEGA_SECRET=секретный_ключ_магазина
```

YandexGPT требует область `yc.ai.languageModels.execute` и роль `ai.languageModels.user`. Адым использует полную YandexGPT Pro 5.1 (`yandexgpt-5.1`), потому что облегчённая Lite заметно хуже справляется со школьными рассуждениями. Распознавание вопросов по умолчанию выполняет локальный Whisper, а настроенный SpeechKit STT служит резервом; `PARENTAI_STT_ENGINE=yandex` меняет их порядок и делает SpeechKit основным. Для STT нужны `yc.ai.speechkitStt.execute` и роль `ai.speechkit-stt.user`, для TTS — `yc.ai.speechkitTts.execute` и роль `ai.speechkit-tts.user`. Документация: [API-ключи](https://yandex.cloud/ru/docs/iam/concepts/authorization/api-key), [модели YandexGPT](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models), [цены AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing), [SpeechKit TTS](https://aistudio.yandex.ru/ru/docs/speechkit/tts/request).

YandexGPT и облачная озвучка SpeechKit платные. Голосовой вопрос сначала распознаётся локальным Whisper; только при ошибке локальной модели настроенный SpeechKit получает законченный фрагмент как резерв. В YandexGPT один раз на новое задание отправляется уже распознанный текст для построения внутреннего плана из трёх подсказок, контрольных вопросов и критерия ответа. Внутреннее решение ребёнку не показывается; следующие подсказки и простые проверки выполняются локально. Камера ребёнка, фотографии аватара и образец голоса родителя в Yandex не отправляются. При явном выборе обычного голоса Яндекса туда отправляется сокращённый до 240 символов текст ответа.

## Тарифы, лимиты и учёт стоимости

Цены и лимиты находятся в одном файле `billing.json`. Денежные значения читаются через `Decimal`, а в SQLite хранятся целыми микро-рублями — двоичное округление `float` не используется. Перед каждым внешним вызовом сервер атомарно резервирует бюджет; после ответа заменяет оценку фактическими токенами или тарифицируемыми блоками. Начатый ответ не обрывается, даже если его фактическая стоимость оказалась выше оценки.

- Бесплатный: 5 занятий по 20 минут, до 3 новых задач и 3 ответов обычным голосом Яндекса за занятие. Максимум — 15 новых задач и 15 блоков TTS в месяц; серверный предохранитель внешних расходов — 25 ₽.
- Адым Плюс: 20 занятий по 30 минут, до 3 новых задач и 10 ответов голосом Яндекса за занятие. Максимум — 60 задач и 200 блоков TTS; цена — 490 ₽, предохранитель — 150 ₽.
- Адым Ультра: 45 занятий по 45 минут, до 4 новых задач и 20 ответов голосом Яндекса за занятие. Максимум — 180 задач и 900 блоков TTS; цена — 990 ₽, предохранитель — 450 ₽.
- Время перерыва в длительность занятия не входит. Голос родителя создаётся локально и не расходует лимит голоса Яндекса. Одна новая задача — одно новое условие домашней работы; уточнения, попытки ребёнка и три последовательные подсказки внутри неё новую задачу не списывают.
- При 80% любого лимита ребёнок видит спокойное предупреждение, а родитель — точный остаток. После лимита текстовая подсказка не заменяется технической ошибкой: например, при исчерпании TTS ответ остаётся на экране.

`data/usage.sqlite3` хранит только агрегаты: идентификаторы пользователя и занятия, тип операции, токены, длительность, блоки, стоимость, провайдера и модель. Текст задания, переписка, фото и аудио туда не записываются. Защита от повторов использует идентификатор запроса; одинаковая параллельная операция не запускается второй раз. Также действуют короткие серверные интервалы и минутные ограничения.

Родительский блок на шаге «К занятию» показывает тариф, количество заданий и подсказок, самостоятельные решения, сложности, стоимость внешних сервисов и остаток лимита. Доступный только администратору агрегированный endpoint `/api/metrics/cost` возвращает P50/P90/P99 стоимости активного пользователя за текущий месяц.

## Подписка через Platega

Три тарифа показаны при входе, а внутри приложения текущий тариф доступен через компактную кнопку «Тариф» в шапке. Она открывает отдельное окно и не перекрывает настройку или занятие. Кнопки Плюс и Ультра создают рекуррентную СБП-подписку на сервере через Platega; Merchant ID и секрет не попадают в браузер. Адым активирует выбранный платный тариф только после callback со статусом подтверждённого списания и проверяет провайдера, тариф, сумму и валюту.

В личном кабинете Platega укажите для callback статуса подписки и callback списания один адрес:

```text
https://ВАШ-ПУБЛИЧНЫЙ-ДОМЕН/api/webhooks/platega
```

По требованиям Platega callback должен быть доступен через публичный HTTPS с доверенным сертификатом: локальный адрес `127.0.0.1` не подходит. До появления публичного развёртывания кнопка и серверная интеграция готовы, но реальная покупка не завершит активацию тарифа. Официальная документация: [авторизация](https://docs.platega.io/), [создание рекуррентной подписки](https://docs.platega.io/%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D0%BA%D1%83-40029698e0), [callback списания](https://docs.platega.io/callback-%D0%BF%D0%BE-%D1%81%D0%BF%D0%B8%D1%81%D0%B0%D0%BD%D0%B8%D1%8E-40029713e0).

Пример при актуальных на 12 октября 2026 года ценах: один план YandexGPT Pro 5.1 на 1200 входных и 500 выходных токенов стоит около 1,36 ₽, один ответ TTS v3 до 250 символов — 0,1626 ₽, а локальное распознавание Whisper не создаёт внешних расходов. Поэтому 3 ответа голосом Яндекса в каждом из 5 бесплатных занятий стоят максимум 2,439 ₽ против прежних 0,4878 ₽ за три ответа на весь месяц — разница всего 1,9512 ₽. Типичный технический максимум внешних расходов составляет около 22,84 ₽ для Бесплатного, 114,12 ₽ для Плюс и 391,14 ₽ для Ультра. Серверные предохранители выставлены немного выше этих оценок, поскольку реальные задачи отличаются по длине. Фактическая стоимость видна в отчёте.

## Реализовано

- Локальная регистрация и вход по логину или почте; закрытые API, записи голоса и аватар доступны только после входа.
- Самостоятельное удаление аккаунта по паролю: удаляются профиль, аватар, голос, занятия, учёт лимитов и сессии.
- Встроенное сканирование без переходов на другие сайты; шесть кадров снимаются автоматически с крупными видимыми и голосовыми подсказками.
- Локальный профиль v7 с сеткой лица, затылком, ушами, волосами, шеей и верхом одежды. Сохранение проверяет формат, порядок кадров, углы, размер и данные ориентиров.
- Плавные повороты головы, кивки, дыхание, моргание и внимание к ребёнку. Lip-sync различает смыкание, округление и растяжение губ, но не является точным фонемным выравниванием.
- Экран занятия с заметным состоянием микрофона, режимом без кнопки, ручной записью вопроса, текстовым вводом и перерывом.
- Диалог с этапами подсказок. Соблюдение педагогической инструкции зависит от YandexGPT и не гарантирует фактическую правильность ответа.
- Единый серверный учёт LLM/STT/TTS по пользователю и занятию, бюджеты трёх тарифов, защита от повторов и отчёт с P50/P90/P99.
- Один скрытый структурированный план на задание; повтор, переход между тремя подсказками и однозначные ответы обрабатываются локально.
- Сменяемые провайдеры: продуктовая логика занятия не зависит от конкретной реализации YandexGPT, STT или TTS. SpeechKit TTS переведён на API v3. XTTS-v2 оставлен только как явно включаемый некоммерческий режим.

## До платной beta

Нужны внешние решения для: получения рабочих реквизитов магазина Platega и публичного HTTPS callback; сценария возвратов и поддержки; юридически допустимого коммерческого голоса родителя вместо XTTS-v2; OCR-провайдера для фото задания и его лимитов.

## Закрытая серверная beta

Серверная версия хранит аватар, голос и созданные аудиофразы отдельно для каждого аккаунта в `data/profiles/<user_id>/`. Общими остаются только модели распознавания и базы учёта. Регистрация поддерживает код приглашения, а общий дневной и месячный бюджет защищает от расходов через массовые бесплатные аккаунты. Для публичного запуска обязательны HTTPS и reverse proxy; готовая инструкция находится в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Ограничения и известные риски

Создание геометрии, MediaPipe и Three.js подходят для MacBook M3 16 ГБ и современных смартфонов. XTTS-v2 не подходит для коммерческой версии из-за лицензии и слишком тяжёл для телефона. Для динамической озвучки используется обычный голос SpeechKit.

Текущая сборка запускается как локальное Python-приложение для macOS. Веб-интерфейс адаптивный, но самостоятельная мобильная упаковка, безопасное хранение ключей и запуск фоновой части на iOS/Android ещё не реализованы. Перенос интерфейса и локальной 3D-реконструкции на телефон возможен; секреты Yandex нельзя помещать в клиентское приложение.

Техническое устройство: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md). Лицензии: [THIRD_PARTY.md](THIRD_PARTY.md).

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
node --test tests/*.test.mjs
node --input-type=module --check < web/app.js
```

Тесты проверяют хранение профиля, геометрию, движение, формы губ, аудио, STT/TTS, диалоги и отмену. Они не измеряют визуальное сходство с конкретным человеком; это нужно оценивать на реальном скане при хорошем рассеянном свете.
