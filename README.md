# ParentAI

ParentAI показывает ребёнку объёмный аватар родителя, следит только за присутствием лица в кадре и помогает с заданиями небольшими подсказками. Three.js и MediaPipe работают в браузере. Сканирование и построение аватара выполняются на устройстве; фотографии родителя не отправляются во внешний сервис. Qwen, Ollama и тяжёлая языковая модель на устройстве не нужны.

## Запуск

На подготовленном Mac дважды нажмите `ParentAI.command` или выполните `.venv/bin/python run_app.py`. Откроется http://127.0.0.1:8766. Если порт занят, добавьте `--port 0`. Завершение сервера — Ctrl+C.

Для новой установки нужен Python 3.11:

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp parentai.env.example parentai.env
.venv/bin/python setup_voice.py --install-model
.venv/bin/python run_app.py
```

XTTS предлагает принять лицензию; приложение не принимает её автоматически. Режим «Моя запись» работает без XTTS, но воспроизводит только записанное напоминание. Новые ответы голосом родителя требуют XTTS. Обычный голос Яндекса быстрее, но использует платный SpeechKit TTS.

## Как пользоваться

1. На шаге «Ваш образ» разрешите локальную обработку и нажмите «Создать мой аватар». Сканер сам сделает шесть кадров: прямо, два небольших и два более сильных поворота, затем портрет с шеей и плечами. Точки вручную расставлять не нужно.
2. Дождитесь объёмного предпросмотра и проверьте поворот. Снимки и профиль сохраняются только в локальной папке `data/`, которая исключена из Git.
3. Запишите голос родителя, прослушайте его и выберите режим ответа.
4. На шаге «К занятию» видно, включится ли микрофон. После начала откроется отдельный экран с аватаром, камерой ребёнка и полем помощи.
5. Ребёнок может сказать «помоги» и вопрос без нажатия кнопки. Сначала аватар даёт подсказки и наводящие вопросы; после нескольких попыток может объяснить решение полностью.

Микрофон без кнопки работает только во время занятия. Локальный фильтр отсеивает тишину, гул и короткие звуки; во время речи аватара вход отключён. Это не распознавание конкретного человека, поэтому речь телевизора иногда может пройти фильтр. Перерыв выключает камеру и микрофон. Камера проверяет присутствие лица, а не внимание или правильность решения.

## Локальный 3D-аватар

MediaPipe строит 478 трёхмерных ориентиров лица. ParentAI выравнивает их в нейтральную позу, создаёт сетку лица и замыкает её объёмной формой затылка. Боковые снимки дополняют текстуру щёк и висков. Портрет используется для цвета волос и одежды. Уши, широкая шея и верх туловища создаются как отдельная объёмная геометрия, согласованная с шириной и высотой лица.

Модель поворачивается как геометрия: фотография не растягивается при повороте. Голова вращается относительно шеи, аватар дышит, моргает, слегка отводит взгляд и плавно возвращается к ребёнку при речи. Рот деформирует губы и нижнюю часть лица; внутри находится тёмная полость без искусственных зубов и языка.

Обычная RGB-камера не видит затылок, точную форму ушей, объём причёски и плечи под одеждой. Поэтому локальный результат рассчитан на фронтальный разговор и небольшие повороты, а не на круговой студийный скан. Волосы и задняя часть головы аппроксимируются. Это ограничение режима без сервера и depth-камеры.

Старые профили v1–v5 сохраняются до успешного нового сканирования, но интерфейс просит создать новый профиль v7. Старые проверенные GLB v6 всё ещё читаются для совместимости.

## Yandex

Заполните `parentai.env` по примеру; файл исключён из Git.

```text
YANDEX_API_KEY=ключ_для_YandexGPT
YANDEX_FOLDER_ID=идентификатор_каталога
PARENTAI_TUTOR_MODEL=yandexgpt-5-lite
YANDEX_SPEECHKIT_API_KEY=ключ_для_SpeechKit
YANDEX_TTS_API_KEY=ключ_для_быстрой_озвучки
```

YandexGPT требует область `yc.ai.languageModels.execute` и роль `ai.languageModels.user`. Для SpeechKit STT нужны `yc.ai.speechkitStt.execute` и `ai.speechkit-stt.user`; для TTS — `yc.ai.speechkitTts.execute` и `ai.speechkit-tts.user`. Если отдельные ключи пусты, используется `YANDEX_API_KEY` с соответствующими правами. Документация: [API-ключи](https://yandex.cloud/ru/docs/iam/concepts/authorization/api-key), [модели YandexGPT](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models), [SpeechKit STT](https://yandex.cloud/ru/docs/speechkit/stt/api/request-api), [SpeechKit TTS](https://aistudio.yandex.ru/ru/docs/speechkit/tts/request).

YandexGPT и SpeechKit платные. В SpeechKit отправляется только законченный фрагмент вопроса после локального обнаружения речи. В YandexGPT отправляются распознанный текст и короткая история задания. Камера ребёнка, фотографии аватара и образец голоса родителя в Yandex не отправляются. При выборе обычного голоса Яндекса туда также отправляется текст ответа для озвучивания.

## Реализовано

- Встроенное сканирование без регистрации и переходов на другие сайты; шесть кадров снимаются автоматически с крупными видимыми и голосовыми подсказками.
- Локальный профиль v7 с сеткой лица, затылком, ушами, волосами, шеей и верхом одежды. Сохранение проверяет формат, порядок кадров, углы, размер и данные ориентиров.
- Плавные повороты головы, кивки, дыхание, моргание и внимание к ребёнку. Lip-sync различает смыкание, округление и растяжение губ, но не является точным фонемным выравниванием.
- Экран занятия с заметным состоянием микрофона, режимом без кнопки, ручной записью вопроса, текстовым вводом и перерывом.
- Диалог с этапами подсказок. Соблюдение педагогической инструкции зависит от YandexGPT и не гарантирует фактическую правильность ответа.
- Потоковая локальная озвучка XTTS: процесс прогревается заранее, образец кэшируется, первые WAV-фрагменты можно воспроизводить до завершения ответа. На Mac M3 используется MPS, если операции поддерживаются.

## Ограничения устройств

Создание геометрии, MediaPipe и Three.js подходят для MacBook M3 16 ГБ и современных смартфонов. XTTS v2 для клонированного голоса слишком тяжёл для телефона; на текущем Mac первый запуск также может занимать заметное время. Для быстрого ответа на слабом устройстве следует выбирать обычный голос SpeechKit.

Текущая сборка запускается как локальное Python-приложение для macOS. Веб-интерфейс адаптивный, но самостоятельная мобильная упаковка, безопасное хранение ключей и запуск фоновой части на iOS/Android ещё не реализованы. Перенос интерфейса и локальной 3D-реконструкции на телефон возможен; секреты Yandex нельзя помещать в клиентское приложение.

Техническое устройство: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md). Лицензии: [THIRD_PARTY.md](THIRD_PARTY.md).

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
node --test tests/*.test.mjs
node --input-type=module --check < web/app.js
```

Тесты проверяют хранение профиля, геометрию, движение, формы губ, аудио, STT/TTS, диалоги и отмену. Они не измеряют визуальное сходство с конкретным человеком; это нужно оценивать на реальном скане при хорошем рассеянном свете.
