# Публичный сайт adym.ru

Это лёгкая статическая витрина для текущего общего хостинга REG.RU. Она не запускает основное приложение и не содержит ключей, аккаунтов, базы пользователей, фотографий, голосов или моделей.

Перед подключением Platega необходимо:

1. добавить действующий адрес поддержки;
2. указать полные реквизиты продавца;
3. заменить предварительные `privacy.html` и `terms.html` окончательными документами;
4. добавить правила отмены подписки и возврата;
5. включить кнопки оплаты только после появления рабочего серверного callback.

Для локальной проверки из корня репозитория:

```sh
python3 -m http.server 8080 --directory public-site
```
