# Публичный сайт adym.ru

Это лёгкая статическая витрина для текущего общего хостинга REG.RU. Она рассказывает о продукте и ведёт в основное веб‑приложение на `https://app.adym.ru/`. Само приложение остаётся на отдельном VDS и не передаёт на общий хостинг ключи, аккаунты, базу пользователей, фотографии, голоса или модели.

`download.html` — единая страница загрузки. Пока подписанных установщиков нет, она предлагает веб‑версию и честно показывает статус macOS и Windows. Когда установщики будут готовы, ссылки нужно добавлять только на проверенные файлы релиза, не на архив исходного кода.

Для согласования с Platega на сайте уже есть:

1. актуальные тарифы и лимиты;
2. полный путь покупки с отдельным экраном заказа;
3. кликабельная заглушка до запуска оплаты;
4. политика конфиденциальности и пользовательское соглашение;
5. отдельная страница поддержки и кодовое слово `OPLAT`.

Адрес `support@adym.ru` должен быть настроен на почтовом сервере домена до передачи сайта на проверку. Реальные `MerchantId`, API‑ключ и callback нельзя размещать в статических файлах: они подключаются только на будущем сервере после одобрения проекта.

Для локальной проверки из корня репозитория:

```sh
python3 -m http.server 8080 --directory public-site
```
