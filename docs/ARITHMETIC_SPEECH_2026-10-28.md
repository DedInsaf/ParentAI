# Арифметика в распознанной речи

Распознанный вопрос проходит проверку повторов и затем консервативное форматирование:

- «семь плюс пять» → `7 + 5`;
- «девять минус четыре» → `9 - 4`;
- «два умножить на три равно шесть» → `2 × 3 = 6`;
- «двенадцать разделить на три» → `12 ÷ 3`;
- «Ответ минус пять» → `Ответ -5`.

Поддерживаются цепочки, скобки, простые числительные, десятичные и обычные дроби,
переменные x/y/z/a/b/c. Значения не вычисляются: ошибочное `2 + 2 = 5` не исправляется
за ребёнка. Дробные операнды заключаются в скобки, чтобы не изменить порядок действий.

Замена возможна только при распознаваемых операндах и точном слове операции.
«У этого способа есть плюс и минус», «На улице минус пять градусов», «Плюс пять
полезных советов», «Мне всё равно» сохраняются словами. Обсуждение написания слов,
неполные выражения, похожие слова и неоднозначные повторы знаков не угадываются.

Отдельно исправлена проверка ответов: минус в `Ответ -5` не считается разделителем
после слова «ответ»; отрицательные дроби остаются отрицательными и равнозначными.

Проверки чистой версии: 173 Python-теста и 114 JavaScript-тестов.
Контекстная проверка предотвращает неверные замены самим форматировщиком;
она не может восстановить исходные слова, если распознаватель уже перепутал их.
