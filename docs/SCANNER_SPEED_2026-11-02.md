# Ускорение создания аватара — 2 ноября 2026

Промежуточная проверка аксессуаров после первого снимка останавливала съёмку
ради отдельной загрузки MediaPipe. Она повторялась при окончательном анализе.
Этот отдельный проход удалён. Все шесть ракурсов снимаются последовательно.
Головной убор и наушники проверяются по итоговой маске до запуска MODNet;
очки по-прежнему разрешены. Снимки остаются в браузере при обработке.

Один worker и по одному экземпляру MediaPipe и MODNet обслуживают оба
итоговых снимка. Качество и разрешение двух проходов удаления фона сохранены.
Worker гарантированно завершается после анализа или ошибки; отмена прерывает
его сразу. Пауза после каждого снимка уменьшена с 1200 до 350 мс, что убирает
5,1 секунды искусственного ожидания на шести снимках. Отображаются этапы
первоначальной загрузки моделей, без обещания уложиться в 30 секунд.

Проверка: 125 тестов JavaScript в чистой копии, включая шесть ракурсов без
промежуточного worker, общий экземпляр моделей на два изображения, сохранение
двух проходов, ранний отказ при головном уборе и отмену с освобождением ресурсов.
В Chrome настоящие модели обработали два искусственных изображения 960×720:
31,5 и 30,8 секунды; по одной загрузке каждой модели на весь цикл. Это локальный
замер без камеры, а не гарантия скорости на устройстве пользователя. Финальное
удаление фона остаётся ресурсоёмким. Пользовательские снимки для проверки
не использовались, тестовая страница на публичный сервер не загружалась.
