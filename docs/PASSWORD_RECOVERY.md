# Восстановление пароля

Кнопка «Забыли пароль?» в форме входа отправляет одноразовую ссылку на почту аккаунта.
Ссылка действует 30 минут. Новый запрос аннулирует прежнюю ссылку; смена пароля
аннулирует все ссылки и сеансы. Токен хранится в SQLite только как SHA-256 хеш.
Ссылка использует фрагмент URL, который не передаётся в HTTP-журналы, и удаляется из адресной строки при открытии.
Аккаунты с блокировкой не получают восстановление. Неизвестная почта получает такой же ответ.
Запросы ограничены по IP, по аккаунту (раз в минуту, до пяти в час) и по числу одновременных отправок.
Письмо является служебным; маркетинговых рассылок нет.

## Настройка отправки на сервере

В закрытый `/opt/adym/parentai.env` добавить (пароль не коммитить):

```dotenv
ADYM_SMTP_HOST=mail.hosting.reg.ru
ADYM_SMTP_PORT=465
ADYM_SMTP_USER=support@adym.ru
ADYM_SMTP_FROM=support@adym.ru
ADYM_SMTP_PASSWORD=пароль_почтового_ящика
```

После изменения перезапустить `adym`. Используется обязательный TLS с проверкой сертификата;
на порту 587 используется STARTTLS. Без настроек форма честно сообщает, что отправка недоступна.
Ошибки отправки записываются без адресов, паролей и ссылок; ссылка неотправленного письма аннулируется.
Приложение не подтверждает конечную доставку в почтовый ящик: принятие SMTP-сервером не исключает спам или возврат.
Проверить доставку на свой существующий аккаунт через «Забыли пароль?», затем пройти ссылку.
Прежний пароль после успешной смены должен перестать подходить, ссылка не должна работать второй раз.

Настройки REG.RU: https://help.reg.ru/support/hosting/nastroyka-pochty-regru/nastroyka-pochty-i-pochtovykh-kliyentovv/nastroyka-pochtovykh-kliyentovv
