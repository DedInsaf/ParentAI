# Публикация исправлений — 31 октября 2026

Опубликована версия f0a2aaf на adym.ru и app.adym.ru. Отдельные незавершённые
эксперименты с голосовыми моделями в эту публикацию не включались.

## Приложение

Изменения применены выбранным патчем поверх работающего экземпляра без сброса
профилей и конфигурации. Перед обновлением выполнена штатная резервная копия,
исходники сохранены в /var/backups/adym-code/legal-20261031/before.tgz.
Сервис перезапущен и активен; smoke-проверка прошла: health, интерфейс,
защитные заголовки, HTTPS и закрытые приватные файлы.
На сервере прошли 4 теста avatar_model и 4 теста payments.

## Основной сайт

Через панель REG.RU опубликованы index, privacy, consent, terms, support,
checkout и checkout-ultra. Все 7 страниц получены заново по HTTPS и побайтово
совпали с подготовленными файлами. Старая версия этих публичных страниц
сохранена локальным архивом /private/tmp/adym-public-before-20261031.zip.
Временный архив переноса на сервере приложения удалён после переноса.
В браузере видна редакция соглашения от 31 октября 2026.

## Аватар: выполненные проверки

- 21 компонент сканера на production совпадает по SHA-256 с локальными
  проверенными файлами; каждый скачивается по HTTPS. WASM отдаётся с
  application/wasm. Проверены модели лица, сегментации и MODNet, библиотеки
  MediaPipe, Three и ONNX Runtime, геометрия, текстуры и сериализация.
- В Chrome в изолированном локальном стенде с аналогичной CSP прошли:
  MediaPipe (478 точек), worker проверки аксессуаров, полный MODNet,
  построение и отображение LocalAvatar, сохранение версии 7 через Runtime,
  повторное чтение свежим Runtime и восстановление/отрисовка модели.
- Использован общедоступный тестовый снимок scikit-image astronaut:
  https://github.com/scikit-image/scikit-image/blob/v0.22.0/skimage/data/astronaut.png
  Фотографии пользователей не читались и не переносились.
- Стенд проверяет компоненты обработки и хранения; это НЕ проверка шести
  живых ракурсов перед камерой и НЕ полный авторизованный сценарий на production.
  Для сборки использован один тестовый снимок в тестовых слотах ракурсов.

## Оставшаяся проверка на production

Автоматическая проверка безопасности отклонила первоначальный сценарий с
публичными служебными файлами и временным аккаунтом/переносом его пароля.
Команда не выполнялась: ни тестовые страницы, ни этот аккаунт не создавались.
Вместо неё выполнен локальный вариант без изменений production.
Запрошено отдельное разрешение пользователя на временный обычный аккаунт
родителя, тестовое сохранение аватара через API и его последующее удаление;
пароль должен оставаться только на сервере, служебных публичных страниц нет.
До получения разрешения этот сценарий не отмечается пройденным.

Правовые вопросы из LEGAL_AUDIT_2026-10-31.md (РКН, реквизиты, договоры,
платёжный цикл, чеки, схема расчётов) публикацией исправлений не закрыты.
