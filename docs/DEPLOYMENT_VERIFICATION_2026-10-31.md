- 21 компонент сканера на production совпадает по SHA-256 с локальными
  проверенными файлами; каждый скачивается по HTTPS. WASM отдаётся с

  MediaPipe, Three и ONNX Runtime, геометрия, текстуры и сериализация.

  https://github.com/scikit-image/scikit-image/blob/v0.22.0/skimage/data/astronaut.png

  живых ракурсов перед камерой и НЕ полный авторизованный сценарий на production.
  Для сборки использован один тестовый снимок в тестовых слотах ракурсов.

## Проверка на production после разрешения пользователя

Первоначальная проверка безопасности отклонила вариант с публичными служебными
файлами и переносом пароля. Эта команда не выполнялась. Пользователь затем
отдельно разрешил временный обычный аккаунт родителя и его удаление.
Использован более узкий сценарий: публичных страниц проверки нет, пароль
генерируется и остаётся только в памяти процесса на сервере.

На https://app.adym.ru выполнены:

- вход во временный обычный аккаунт (роль parent, бесплатный тариф);
- сохранение аватара версии 7 и масок портрета через настоящий API;
- получение сохранённого аватара и проверка совпадения данных;
- отказ на повреждённую замену, сохранение предыдущего рабочего аватара;
- выход, проверка закрытого доступа без входа, повторный вход и восстановление;
- удаление тестового аккаунта штатным API, проверка отсутствия пользователя
  и его папки профиля; временный файл тестового снимка/модели удалён.

Все перечисленные проверки прошли. Первая попытка тестового клиента не передала
X-App-Token при GET и получила ожидаемый защитный ответ 403; аккаунт был удалён
в finally. После исправления клиента весь сценарий повторён успешно.
Приложение для этого не менялось: браузерный клиент уже передаёт этот заголовок.
Съёмка шести живых ракурсов перед камерой пользователя не выполнялась.

Правовые вопросы из LEGAL_AUDIT_2026-10-31.md (РКН, реквизиты, договоры,
платёжный цикл, чеки, схема расчётов) публикацией исправлений не закрыты.
