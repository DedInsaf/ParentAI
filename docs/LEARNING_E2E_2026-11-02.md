# Сквозная проверка адаптивного занятия — 2 ноября 2026

## Найденные и исправленные ошибки

- Краткий ответ словами с точкой (типичный результат распознавания речи),
  составные числительные и «У меня получилось…» не всегда считались попыткой.
  Добавлена обработка конечной пунктуации и числовых форм без ослабления
  отдельной строгой проверки правильности ответа.
- После дополнительного объяснения правильный ответ всё ещё мог помечаться
  как «минимум помощи». Уточнения теперь учитываются отдельно; простое
  подтверждение «понятно» не считается новой помощью.
- «Повтори» после уточнения воспроизводило исходную подсказку вместо последнего
  объяснения. Последняя реплика хранится только во временной сессии и повторяется
  без продвижения уровня и нового запроса к модели.
- Рекомендации и режим маленьких шагов опирались на всю историю трудностей и
  не учитывали успешное повторение. Используются последние пять заданий темы;
  два последних решения с минимумом помощи закрывают рекомендацию. Новая
  реальная трудность открывает её снова. Сам переход к другому заданию не
  трактуется как учебная ошибка.
- Порядок событий, начатых в одну секунду, зависел от SQLite. Добавлен стабильный
  порядок по времени и rowid.

## Сохранность старых данных

Подробная оценка помощи использует learning_version=2 и новый счётчик
clarification_requests. Прежние итоги и общие счётчики не удаляются. Для старых
заданий нельзя восстановить неизвестное число уточнений, поэтому они явно
отмечаются как не включённые в новое сравнение помощи. Полные вопросы и ответы
для этого не сохраняются. Удаление аккаунта очищает те же строки lessons,
новых отдельных хранилищ персональных данных не добавлено.

## Сценарий сквозной проверки

Повтор → уточнение → ошибочный голосовой ответ → правильный ответ → новое
задание → два успешных коротких повтора темы → полный разбор другого задания.
Сверить фактические попытки, уточнения, верные решения, объём помощи,
рекомендацию, вывод родителю, ограничения тарифа и аудио.

## Фактически выполнено

- Чистая сборка из Git и только выбранных исправлений: 192 теста Python,
  121 тест JavaScript — успешно. На сервере отдельно: 14 тестов обучения и
  6 тестов сквозного диалога.
- На app.adym.ru создан временный обычный родитель с тестовым тарифом Плюс.
  Через HTTPS API выполнены два занятия, пять задач и 15 реплик. Использованы
  настоящий YandexGPT и голос Адым, проверены WAV и временные метки артикуляции.
  Клонирование голоса родителя в эту проверку не входило.
- Искусственная запись «У меня получилось тринадцать» распознана локальным
  Whisper как «У меня получилось 13.». Зафиксирована ровно одна ошибка.
- «Почему?» дало объяснение текущего шага; «Повтори» вернуло его дословно.
  После ответа 12 задача завершилась верно, с дополнительной помощью.
- После первой трудности: завершено 1, минимум помощи 0, рекомендация есть.
  После одного чистого решения: 2 / 1, рекомендация остаётся.
  После двух: 3 / 2, рекомендация исчезла.
  После нового полного разбора: 5 / 3 (60%), рекомендация снова появилась.
  Общий отчёт: пять задач, четыре решения без готового решения; полный разбор
  не записан как правильное самостоятельное решение.
- После проверки тестовая подписка снята, аккаунт удалён штатным API;
  отсутствие аккаунта и каталога профиля подтверждено. Пароль оставался
  только в памяти на сервере, публичных тестовых страниц не создавали.
- В Chrome локально пройден тот же путь интерфейса на искусственном профиле:
  подсказка, уточнение, повтор, неверный ответ с точкой, верный ответ, возврат
  родителю. Отображены 1 задача, 1 верное решение, 1 несовпадение и 1 уточнение,
  минимум помощи 0. Рекомендованная задача переносится в поле нового занятия.
- Дополнительно исправлено сохранение старой переписки на экране нового
  занятия. Черновик рекомендованной задачи сохраняется, сообщения очищаются.
  Кнопка подготовки теперь явно подтверждает действие и учитывает отмену.
- Проверка опубликованного сервиса: HTTPS, health, интерфейс, защитные
  заголовки и недоступность приватных файлов — успешно.
