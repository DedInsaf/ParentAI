# Аналитическая база Адым

Выполните из корня проекта:

```bash
./scripts/fetch_admin_db.sh
```

После этого откройте `analytics/adym-admin.sqlite3` в VS Code с расширением SQLite Viewer или в окне Database в PyCharm Professional. Это копия только для чтения; сервер обновляет исходный экспорт каждые пять минут.

В базе доступны аккаунты, тарифы, входы, последняя активность, занятия, подсказки, успешность, обращения к моделям, ошибки, расходы, платежные статусы и действия администратора. В ней нет хешей паролей, ключей сессий, текстов заданий, расшифровок речи, фотографий и аудио.
